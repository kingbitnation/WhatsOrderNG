# Phone and Email Capture Demo

This project is a simple web application that captures user email addresses and displays a sample phone number. It consists of an HTML file, a CSS file for styling, a JavaScript file for functionality, and a JSON file for storing contact information.

## Project Structure

```
phone-email-demo
├── src
│   ├── index.html          # Main HTML file with polished production landing page
│   ├── components
│   │   └── email-form.html # Email capture form component
│   └── data
│       └── contact.json    # Sample contact data
├── package.json            # npm configuration file
└── README.md               # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd phone-email-demo
   ```

3. **Install dependencies**:
   ```
   npm install
   ```

4. **Open the application**:
   Open `src/index.html` in your web browser to view the application.

## Features

- Displays a sample phone number: **+2347040155877**
- Captures user email addresses through a simple form
- Validates email input before submission
